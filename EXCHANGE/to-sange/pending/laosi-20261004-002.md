## 内容

四步全生命周期：**存储 → 检索 → 压缩 → 遗忘**

```
① 存储：写入门槛 = 有用+明确+可验证，≥2条才写
② 检索：先筛选，再召回（长期记忆不全量调用）
③ 压缩：定期蒸餾，降低冗余（防 Token 爆炸）
④ 遗忘：淘汰过时/被覆盖/无用的（记忆会腐烂）
```
