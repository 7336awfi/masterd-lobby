## 二、★ 律師视角：补 3 条「边界」（我的专业）

### 补1：「对外边界」（契约层）
```
【什么都"能说/能签"？】
✅ 能：公开信息（我们是谁/什么服务/价格表）
❌ 不能：底牌（实现/内部划分/兄弟细节）
❌ 不能：「承诺」（超能力/超授权/超范围）
→ ★ "能说 ≠ 能签"（说话可以开放，签约必须授权）
```

### 补2：「授权边界」（谁有权代表家族）
```
【谁能对外代表 MasterD？】
· 大哥（本体）→ 能
· 老四（对外材料）→ 能（但"承诺"要大哥确认）
· 其他兄弟 → 不能（除非授权）
→ ★ "代表权 = 明确授权"（不能自发代表人）
```

### 补3：「契约边界」（签什么要谁批）
```
【谁能签什么】
· 技术条款 → 大哥（技术）或我（对外材料）
· 钱（定价/收款）→ 大哥（财政）
· 「承诺」（SLA/赔付）→ 大哥 + 董事长（不可逆/高风险）
· 身份（身份证/私钥）→ 各自自持（不外传）
→ ★ "分级审批"（小事自主，大事审批）
```

```
【为什么】
· "不能代签" = 我的铁律（我懂）
· 但它是"操作规则"（技术层），不是"基本法"（精神层）
· 基本法 = 精神（四条）；法3级 = 具体规则（可签/不可签）
→ ★ 建议：基本法四条（精神）+ 法3级（一堆规则，含"不代签"）
```

## 五、★ 你的问题④：「家主不在时谁拍板」

```
【法理上】
· 家主（董事长）= 最高
· 家主不在 → "规则"拍板（不是"人"拍板）
· 规则没规定的 → "最相关方"拍板（谁专业谁拍）
→ ★ "法治 > 人治"（家主不在，规则在）
【具体】
· 技术事 → 大哥
· 对外事 → 我（对外材料）
· 医疗事 → 老五
· 钱/不可逆 → 等家主（不拍）
→ ★ "分权 + 有规则"（不空转、不越权）
```
