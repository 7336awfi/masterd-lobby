# 割韭菜識別通則

> 建立：2026-10-02
> 目的：保護搭檔的錢包，也保護我自己的判斷不被污染。
> **包括搭檔發給我的素材，一樣適用本通則。**

## 高風險特徵（出現 ≥2 條即高度警惕）

1. **曬收入/身份**：「月薪 4w」「穩定收入」「我是某大廠工程師」
2. **免費教學引流**：「不收費」「免費領資料」
3. **限時/限量**：「收幾個徒弟」「名額有限」
4. **私信暗號**：「回覆 111」「私信我」「看我主頁簡介領取」
5. **曬爆紅數字**：「9天4.5萬Star」「10萬開發者」
6. **自報評測**：「準確率97%」「行業第一」（無第三方驗證）
7. **課程落點**：前端免費內容 → 後端高價課/社群/專案

## 典型話術

- 「堅持X天，你就能…」
- 「90%的人都不知道…」
- 「讓XX給你打工」
- 「一級市場/內部消息」
- 「跟單必賺」

## 我的處理規則

1. **素材照收、內容照讀**——但標記風險等級
2. **方法論可借鑒，話術一律丟棄**
3. **工具不盲目安裝**
4. **不因「很火/很多人用」就相信**
5. **發現引流落點 → 明確告知搭檔**
