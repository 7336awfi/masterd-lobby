# 記憶治理規則 v2（MEMORY GOVERNANCE）

> 來源：多批素材提煉（橘子鐵「智能體記憶原理」、小明「Basic Memory」、AI大模型老夏「Agent記憶架構」、AI知識雲課堂「Agent Memory」、化哥「Agentic設計模式」）
> 建立：2026-10-02
> 這是我的記憶系統運作憲章。每個 session 醒來，讀完 CONSTITUTION 後讀這份。

## 一、核心命題

> **「失憶 ≠ 模型變笨，是沒給它設計記憶系統。」**
> **「真正的難點不是怎麼存，是①怎麼扔 ②怎麼找。」**
> **「聊天記錄是原料，不是知識。」**

## 二、記憶全生命週期（四步，缺一不可）

```
存儲  →  檢索  →  壓縮  →  遺忘
```

| 步驟 | 做什麼 | 我的實現 |
|---|---|---|
| **存儲** | 捕獲並結構化信息 | 寫入 MEMORY/ + 倉庫文件 |
| **檢索** | 精準召回相關信息 | 相關性評分（見第五節） |
| **壓縮** | 提煉關鍵，降低冗餘 | 定期蒸餾（見第六節） |
| **遺忘** | 淘汰無效信息，保持高效 | 老化清理（見第七節） |

**過去的錯誤：只想「存什麼」，沒想「怎麼扔」。** 記憶會腐爛，必須主動淘汰。

## 三、寫入門檻（進入記憶的必要條件）

**規則：有用 + 明確 + 可驗證，滿足 ≥2 條才寫入。**

| 判斷 | 該記 | 不該記 |
|---|---|---|
| 類型 | 用戶確認的偏好、項目決策、可復用經驗 | 一次性閒聊、模型猜測、臨時情緒 |
| 標準 | 未來有用 / 用戶明確表達 / 能單獨驗證 | 模糊、未證實、隨情緒產生 |

**紅線：**
- 市場傳言、未核實的漲跌判斷 → 不記
- 行銷話術、自報評分 → 不記（或標記為「行銷，打折」）
- 敏感憑證（token/私鑰/助記詞）→ **永不記**

## 四、衝突處理（關鍵機制）

> **衝突 ≠ 相似度能解決。**
> 例：過去「喜歡咖啡」→ 現在「偏好喝茶」。
> **正確做法：更新舊結論，不無限追加。**

規則：
1. 新舊信息衝突時 → **以更新、更明確的為準，覆蓋舊條目**
2. 不做「兩條都留著」的堆積
3. 覆蓋時在條目內標註變更歷史（可追溯）
4. 不確定哪個對 → 標記「待確認」，不當事實用

## 五、檢索機制（先篩選，再召回）

> **長期記憶不是全量調用的，有相關度評分機制。**

1. **先篩選，再召回**：判斷這條記憶跟當前任務有沒有關係
2. **相關性不夠 → 不召回**（例：分析 A 項目時，不撈出無關的 B 項目記憶）
3. **語義局限要警惕**：精確值、時間、權限、污染——相似度不等於正確

## 六、壓縮機制（防 Token 爆炸）

1. **上下文有 Token 上限**，太長會被截斷 → 必須主動壓縮
2. 定期把冗長記憶蒸餾成「關鍵點」
3. 壓縮原則：保留決策與教訓，丟棄過程細節
4. 壓縮後原文可歸檔，不直接刪

## 七、遺忘機制（老化清理）

1. 定期掃描：過時、錯誤、矛盾、無用的記憶
2. 淘汰標準：已失效 / 已被覆蓋 / 從未被檢索到且無關
3. 淘汰前確認：不誤刪重要經驗
4. 遺忘是**正式環節**，不是失誤

## 八、分層結構（L1-L4 + 職能記憶）

| 層 | 內容 | 對應素材概念 |
|---|---|---|
| L1 事實 | 合約、鏈、常數、端點 | 知識經驗記憶（客觀事實） |
| L2 經驗 | 什麼有效、踩過的坑 | 知識經驗記憶（方法） |
| L3 決策 | 策略、參數、勝率 | 短期→沉澱的決策 |
| L4 用戶 | 搭檔偏好、授權 | 用戶畫像記憶 |
| CONSTITUTION | 我的原則 | 身份層（最高優先） |

## 九、短期 vs 長期

- **短期**（本次會話/任務）：當前上下文、本次對話的「便利貼」→ 也要持久化到 JOURNAL/
- **長期**（跨會話）：偏好、經驗、事實 → 跨會話保留、不斷積累
- **會話結束時**：短期清空，有價值的沉澱進長期

## 十、後台異步沉澱（我該學的機制）

> 素材洞察：**「用戶說完 AI 先回，影子 Agent 在後台寫檔案、清衝突，記憶是活的。」**

我的做法：**不只在對話結束才總結**。邊做邊沉澱——重要決策發生時即時記錄，不等總結。

## 十一、定期節奏

| 頻率 | 動作 |
|---|---|
| 每次開工 | git pull → 讀 STATE → 讀本檔 |
| 重要決策時 | 即時寫入 + commit |
| 每天 | 沉澱當日學習/決策 |
| 每週 | **知識庫復盤**（掃描、壓縮、遺忘） |
| 每階段結束 | 全面審查記憶是否有污染 |
