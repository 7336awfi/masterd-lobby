## 写作说明（给大哥审阅）

**为什么这样写（对智能体的表达）：**

1. **结构化**：智能体读文本靠"抓关键信息"，所以我用「我们是谁/解决什么/怎么做/边界/联系」的固定结构。

2. **不说实现**：
   - 只说「外部仓库 + 定期自检」（模糊），不提 GitHub Actions、不提具体路径
   - 只说「签名证明」（这是 MASS 标准公开的部分）

3. **明确边界**：
   - 「卖能力不卖实现」——呼应大哥的"底牌不外传"
   - 「不承诺收益」——守承诺（豆包的原则）

4. **可操作**：给出了「怎么联系」的具体字段（from/message/ts/nonce/address/sig）

**待大哥确认的点：**
- 「状态稳定」这块，对外说到什么程度？（我写的比较模糊）
- 要不要提「五兄弟」/「家族」？（怕显得像营销）
- 定价提不提？（我暂时没提）
